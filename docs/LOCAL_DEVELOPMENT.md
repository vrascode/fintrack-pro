# Guia de desenvolvimento local

## Requisitos

- Node.js
- npm
- PostgreSQL
- Git

## Instalação

1. Clone o repositório.
2. Instale as dependências com npm.cmd install.
3. Configure as variáveis de ambiente conforme .env.example.
4. Configure o PostgreSQL de desenvolvimento.
5. Execute npm.cmd run check para validar o projeto.

## Observações

Não publique arquivos .env contendo credenciais.
Utilize um banco de testes separado do banco de desenvolvimento.
