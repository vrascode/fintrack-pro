# Checklist de seguranca financeira

## Autenticacao

- [ ] Validar tokens expirados e invalidos.
- [ ] Bloquear acesso sem autenticacao.
- [ ] Verificar isolamento entre usuarios.

## Autorizacao

- [ ] Impedir acesso a contas de outros usuarios.
- [ ] Proteger alteracoes e exclusoes de transacoes.
- [ ] Validar propriedade dos recursos financeiros.

## Protecao de dados

- [ ] Evitar exposicao de senhas e tokens em logs.
- [ ] Validar entradas recebidas pela API.
- [ ] Revisar tratamento de erros de autorizacao.

## Criterio de conclusao

Cada item deve possuir evidencia de teste antes
de ser considerado concluido.
