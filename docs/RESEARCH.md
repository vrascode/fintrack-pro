## Recommendations and assumptions / Recomendações e hipóteses

- Original ink/teal/ivory identity, readable type and clear empty states.
  / Identidade original em tinta/verde-petróleo/marfim, legibilidade e estados vazios.
- Prioritize trustworthy user-entered records and transparent status. No demand,
  market-share or savings claims inferred from competitor marketing.
  / Registros confiáveis; marketing não comprova demanda ou resultados.
- No financial fixtures in foundation screens; user research is still pending.
  / Sem dados financeiros fictícios; pesquisa com usuários pendente.
- Pin compatible dependencies and keep the generated lockfile. Terminal npm registry
  access failed with EACCES; offline cache availability limits installation/checks.
  / Acesso npm bloqueado; uso e limites do cache local serão registrados.
