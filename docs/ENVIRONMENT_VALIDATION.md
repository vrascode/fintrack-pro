# Verificacao do ambiente de desenvolvimento

## Objetivo

Registrar os procedimentos para verificar se o
ambiente local do FinTrack Pro esta configurado.

## Validacoes

- [ ] Confirmar a versao do Node.js.
- [ ] Confirmar a versao do npm.
- [ ] Verificar a conexao com PostgreSQL.
- [ ] Confirmar as variaveis de ambiente.
- [ ] Executar os testes automatizados.
- [ ] Validar a compilacao da aplicacao.

## Resultado

Registrar falhas encontradas e as correcoes
necessarias antes de publicar uma nova versao.
