# Checklist de regressao financeira

## Testes essenciais

- Cadastro e autenticacao.
- Isolamento de dados entre usuarios.
- Criacao e edicao de transacoes.
- Transferencias entre contas.
- Calculo de saldo e resultado mensal.
- Orcamentos por categoria.
- Metas e contribuicoes idempotentes.
- Relatorios e exportacao CSV.
- Persistencia real com PostgreSQL.

## Comandos

npm.cmd run lint
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:e2e
