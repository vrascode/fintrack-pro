# Guia de idempotencia

Evitar duplicacao de operacoes financeiras.

## Criterios de verificacao

- [ ] Identificar operacoes com chave de idempotencia
- [ ] Repetir requisicao com a mesma chave
- [ ] Verificar ausencia de lancamento duplicado
- [ ] Testar chave reutilizada com dados conflitantes
- [ ] Validar comportamento em falhas de rede
- [ ] Registrar evidencias dos testes

## Evidencias

Registrar ambiente, data, resultado dos testes
e referencias para as alteracoes implementadas.
