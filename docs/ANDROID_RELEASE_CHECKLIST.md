# Checklist de publicação Android

## Preparação

- [ ] Confirmar nome e identificador do aplicativo.
- [ ] Revisar ícone e tela de inicialização.
- [ ] Configurar ambiente de produção.
- [ ] Confirmar URL HTTPS da API.
- [ ] Remover referências a serviços locais.

## Funcionalidades

- [ ] Validar cadastro e login.
- [ ] Validar recuperação de sessão.
- [ ] Testar contas e transações.
- [ ] Confirmar persistência após reiniciar.
- [ ] Testar falhas de conexão.

## Qualidade

- [ ] Executar lint e verificação de tipos.
- [ ] Executar testes automatizados.
- [ ] Testar em dispositivo Android real.
- [ ] Revisar permissões solicitadas.
- [ ] Verificar desempenho e navegação.

## Distribuição

- [ ] Configurar assinatura do aplicativo.
- [ ] Gerar build de teste.
- [ ] Validar instalação e atualização.
- [ ] Preparar política de privacidade.
- [ ] Revisar requisitos da loja.

## Estado

Este documento é um checklist de preparação.
Não confirma que uma build Android foi publicada.
