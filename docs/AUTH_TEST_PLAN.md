# Plano de testes de autenticacao

Validar cadastro, login e protecao de recursos.

## Criterios de verificacao

- [ ] Cadastrar usuario com dados validos
- [ ] Rejeitar email invalido e senha fora das regras
- [ ] Rejeitar credenciais incorretas
- [ ] Validar acesso autenticado aos endpoints
- [ ] Confirmar persistencia apos reiniciar a API
- [ ] Impedir acesso a dados de outro usuario

## Evidencias

Registrar ambiente, data, resultado dos testes
e referencias para as alteracoes implementadas.
