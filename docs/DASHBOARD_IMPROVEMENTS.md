# Melhorias do dashboard

## Objetivo

Melhorar a leitura dos dados financeiros sem alterar os calculos existentes.

## Criterios de aceitacao

- Graficos com valores reais e periodos identificados.
- Receitas e despesas visualmente diferenciadas.
- Estados vazios compreensiveis.
- Valores monetarios com precisao em centavos.
- Layout adaptado para celular e desktop.
